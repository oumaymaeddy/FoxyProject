# 🦊 Foxy Adventure — 2D Platformer Game

A 2D platformer game developed with Unity and C#. 
Players control Foxy through levels, collecting items and avoiding enemies.

## 🎮 Gameplay Features

- 🏃 **Movement & Jump** — smooth character controls
- 💥 **Collision System** — precise environment interaction
- 🎬 **Animations** — fluid character and enemy animations
- 🏆 **Item Collection** — collectibles throughout levels
- 👾 **Enemy AI** — enemies to avoid and defeat

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Unity | Game engine |
| C# | Game logic and scripting |
| Unity Animator | Character animations |
| Unity Physics | Collision and movement |

## 🚀 How to Run

1. Clone the repository
2. Open the project in **Unity Hub**
3. Open the main scene
4. Press **Play** in the Unity Editor
